# Lampiran B — Placeholder di web yang HARUS dikoreksi

Catatan internal, bukan pertanyaan ke client. Data berikut masih bawaan template
dan salah kalau dibiarkan tayang.

* **Harga** — sudah diganti dari USD ke IDR (`Rp 250.000`/sesi 50 menit,
  `Rp 900.000` paket 4 sesi, hemat `Rp 100.000`/bulan). **Angka ini masih
  placeholder**, menunggu harga asli dari client. Catatan: blok harga ini ada di
  `messages/id.json` tapi belum dirender di halaman mana pun — perlu diputuskan
  apakah section harga mau ditampilkan di landing page atau tidak.
* **Klaim "Sesuai HIPAA"** (footer, fitur, FAQ) — HIPAA regulasi Amerika, tidak
  relevan untuk klinik di Indonesia. Ganti ke bahasa perlindungan data yang netral.
* **"Kami menerima sebagian besar rencana asuransi"** — belum dikonfirmasi
  client, berisiko jadi salah janji.
* **Hotline krisis `741741 Crisis Text Line`** — nomor Amerika. Kalau section
  krisis tetap dipakai, cukup 119 ext. 8 (SEJIWA).
* **"Tersedia secara nasional"** di footer — padahal layanan hanya di Batam.
* **"Bergabunglah dengan ribuan keluarga"** — angka fiktif.
* **Copyright footer masih 2024.**
* **Form kontak belum terkirim ke mana-mana** — masih `setTimeout` + `alert`,
  belum ada email/WhatsApp tujuan. Butuh keputusan client mau masuk ke mana.
